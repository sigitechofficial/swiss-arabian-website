# Swiss Arabian Website

Customer storefront for Swiss Arabian. Architecture mirrors the admin panel (`docs/ADMIN_PANEL_PROJECT_OVERVIEW.md`).

See **[docs/PROJECT_OVERVIEW.md](./docs/PROJECT_OVERVIEW.md)** for structure, stack, and conventions.

## Local run

```bash
cp .env.example .env
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality

```bash
npm run quality
```
